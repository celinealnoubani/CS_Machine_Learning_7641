# CS 7641 - Machine Learning

**Georgia Institute of Technology**

## Overview

This repository contains my coursework for CS 7641 Machine Learning, covering fundamental algorithms and techniques in supervised learning, unsupervised learning, and deep learning. All implementations are built from scratch using NumPy to demonstrate understanding of the underlying mathematics.

## Course Structure

| Assignment | Topics | Key Implementations |
|------------|--------|---------------------|
| [HW1](./HW1) | Programming Warm-Up | NumPy fundamentals, vectorization, broadcasting |
| [HW2](./HW2) | Clustering | K-Means, GMM, DBSCAN |
| [HW3](./HW3) | Regression & Classification | PCA, Linear/Ridge Regression, Logistic Regression |
| [HW4](./HW4) | Neural Networks & Ensembles | Multi-layer NN, CNN, Random Forest, SVM |
| [Project](./Project) | Course Project | - |

## Technical Skills Demonstrated

### Machine Learning Algorithms
- **Unsupervised Learning**: K-Means, K-Means++, Gaussian Mixture Models, DBSCAN, PCA
- **Supervised Learning**: Linear Regression, Ridge Regression, Logistic Regression, Random Forest, SVM
- **Deep Learning**: Multi-layer Neural Networks, Convolutional Neural Networks

### Optimization Techniques
- Gradient Descent (Batch, Stochastic, Mini-batch)
- Adam Optimizer
- Cross-validation for hyperparameter tuning

### Mathematical Foundations
- Expectation-Maximization (EM) algorithm
- Backpropagation derivation and implementation
- Regularization (L2, Dropout)
- Numerical stability techniques (log-sum-exp, softmax stabilization)

## Technologies Used

- **Python 3.11+**
- **NumPy** - Vectorized computations
- **PyTorch** - CNN implementation
- **Matplotlib/Seaborn** - Visualization
- **Scikit-learn** - Evaluation metrics and utilities
